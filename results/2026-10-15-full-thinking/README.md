生成墙钟时间包含图像预处理和排队，不包含模型加载、通用图片检查、Blender 渲染及评分。32B 每个实例使用双卡张量并行，其他模型每实例单卡。本轮 Qwen3.6 thinking 续跑时将未完成题分给两个相同的单卡副本；已经完成的回答保留，中断时尚未完成的请求按原参数恢复。各组时间不能直接作为相同硬件吞吐量比较，中断前未完成请求的额外计算不包含在最终回答 token 统计中；完整计时覆盖不足时标为 N/A。
思考和答案 token 按原生 `</think>` 分界统计，分隔符本身不属于两者，因此两者之和可能略小于总输出。未结束思考即耗尽预算的回答记为截断失败，只执行最终答案中的完整程序。

Qwen3-VL 的两种模式使用官方 Instruct / Thinking 不同权重，差异不能单独归因于开关；Qwen3.6-27B 使用同一多模态权重的 enable_thinking=False / True。
输入均为起始代码和有效相机的当前/目标图片。成功判定沿用模型评测前冻结的类别相对像素误差阈值，属于本实验的近似视觉成功指标，不是 BlenderGym 官方二元分数。每类只有两题用于阈值校准，因此另外列出排除校准题的分数。

数据处理：blendshape73、geometry13、geometry44 起始和目标程序相同；lighting1–5 的 render5.png 无对应相机，输入与评分均去掉该视角。参考变化低于渲染噪声阈值的任务也会被判为数据无效。本轮实际排除 3 题，所有排除原因见 results.json。

本轮解码采样和预算不同于先前贪心 8192-token 筛选，应作为独立实验阅读。
